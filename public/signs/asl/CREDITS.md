# ASL handshape images

The `a.png` … `z.png` files are the ASL fingerspelling handshapes used on the
Learn › letter pages.

- **Source:** "American ABCs" clip-art set by [wpclipart.com](http://www.wpclipart.com/legal.html),
  mirrored on Wikimedia Commons as `File:Sign language A.svg` … `File:Sign language Z.svg`.
- **License:** Public domain. wpclipart.com released the work into the public
  domain worldwide ("grants anyone the right to use this work for any purpose,
  without any conditions").
- **Retrieved:** Wikimedia Commons thumbnail service
  (`https://commons.wikimedia.org/w/thumb.php?f=Sign_language_<L>.svg&w=600`),
  rasterised to 600px-wide transparent PNGs.
- **Note:** J and Z are motion letters. These images show the **starting** pose;
  the app adds an arrow overlay and movement text to describe the traced path.

No attribution is legally required, but we credit the source to be respectful of
the original author.
